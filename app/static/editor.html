Фрагмент для прослушивания

Его услышат все в общем списке песен.

На дорожке он подсвечен сверху.

Обложка

jpg / png / webp до 5 МБ, обрежется в квадрат 512×512. Она же — значок мода в Мастерской.

Live-запись

«● Запись» — песня играет с текущего места, вы жмёте клавиши в такт, ноты ставятся сами (с направлением; держите дольше ~0,6 с — удержание). Потом поправьте точечно. Всю запись отменяет один Ctrl+Z.

Привязка (к удару / ½ / ¼) действует и на запись.

Обрезка песни

Оставьте нужный кусок загруженной песни (не меньше 20 с). Ноты сдвинутся вместе с ним, ноты вне куска уберутся. Исходная песня хранится — обрезку можно поменять или вернуть всю песню.

Как править

Клик по нижней части дорожки — поставить ноту или выбрать её; тяните, чтобы сдвинуть (выбранные — все вместе). Клик по волне — перемотка; колесо — прокрутка, Ctrl+колесо — масштаб.

Кисть — выберите направление и ставьте ноты подряд, каждая получит его. Правка — кнопки меняют выбранные ноты. Направления: 1–5 = ↑ ↓ ← → E, 0 = 🎲 (в каждой игре своя случайная клавиша), Q — следующее по кругу, B — Кисть / Правка. Удержание — любая клавиша.

Shift+клик — добавить / убрать ноту из выбора, Shift+протянуть — выбрать отрезок, Ctrl+A — все, Esc — снять выбор. Alt+клик (или протянуть) — стереть. Ctrl+клик по ноте — следующее направление. H — удержание, Delete — удалить выбранные. Shift+← → — сдвинуть выбранные на шаг привязки, ← → — к соседней ноте. Ctrl+C / Ctrl+V — копировать выбранные и вставить с места курсора (повторить припев). Ctrl+Z / Ctrl+Y — отменить / вернуть, Ctrl+S — сохранить, Пробел — играть / пауза.

X — зеркало выбранных (← ↔ →, ↑ ↔ ↓): припев повтором наоборот. F — заполнить по сетке: между первой и последней выбранной нотой ставится нота на каждом шаге привязки (направление — кисть). M — метроном, «Скорость» 0,75× / 0,5× — расставлять медленно (и записывать тоже).
