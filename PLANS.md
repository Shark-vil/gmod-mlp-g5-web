# Планы сайта

## Отложенные вопросы (решить потом)
- Фильтр стоп-слов ищет подстроку: «ass» срабатывает в «class», «bass». Вариант: `слово` — целое слово,
  `*слово*` — где угодно. Пока оставлено как есть.
- Название и описание мода в Мастерской автор может поменять после одобрения. Вариант: перепроверять
  опубликованные песни раз в 6 часов. Пока проверяются при отправке на проверку и при одобрении.
- Показывать ли автору скрытой песни, где сработал фильтр (без самого слова). Пока — только общее сообщение.

## Модерация, жанры, теги, возраст (с 14.10.2026, от простого к сложному)
- [x] 1. «скрыта словом» → «скрыто фильтром», подсказка при наведении со всеми срабатываниями
      (слово и где: название, исполнитель, теги, источник, название / описание мода в Мастерской).
- [x] 2. Страница правил `/rules` (ru / en), ссылки на неё: загрузка, редактор, отказ фильтра.
- [x] 3. Страница перехода `/away?r=<url>`: предупреждение о внешнем сайте, домен крупно, «Перейти» / «Назад».
- [x] 4. Ник автора со стоп-словом не скрывает песни: вместо ника — «штрихкод», ссылка на профиль остаётся
      (сайт и `GET /api/v1/songs/game`).
- [x] 5. Поле «Источник» (ссылка на оригинал, http / https) в редакторе; на странице песни — через `/away`.
      Меняется вместе с версией (на проверку).
- [x] 6. Возрастные метки в редакторе: мат (немного / больше 20 % текста), эротический подтекст →
      мат — 16+, подтекст — 16+, оба или мат > 20 % — 18+. Плашки в списках. Сайт по умолчанию скрывает 16+ / 18+,
      включаются в фильтре списка. Повышение метки действует сразу, понижение — после проверки.
- [x] 7. Жанры: список у админа (тот же редактор, что у стоп-слов, строка «Русский | English»), стартовый набор,
      у песни 1–3 жанра, меняются без проверки; фильтр по жанру в списке.
- [x] 8. Теги: облачка (Enter / запятая), вставка «a, b» и «#a #b» (# убирается), нижний регистр,
      2–30 символов, до 10 штук; подсказки из тегов опубликованных песен; клик по тегу — поиск; меняются с проверкой.
- [x] 9. Фильтр при отправке на проверку: название, исполнитель, теги, источник, название и описание мода →
      отказ «Мод не прошёл автоматическую фильтрацию контента…» + ссылка на правила.
- [x] 10. Доверие автора: +1 за одобрение админом, −3 за отклонение, −1 за отказ фильтра (не чаще раза в сутки
      на песню). С 5 очков — «проверенный автор» (галочка), обновления опубликованных песен одобряются сами
      (фильтр работает). Снимается ниже 2 очков — одна ошибка галочку не снимает. Админ может выдать / снять вручную.
- [x] 11. Игра: метки 16+ / 18+ скрыты по умолчанию — серверная настройка `mlp_dance_max_age` в меню режима;
      поиск в лобби и по тегам / жанрам.
